# Security

If you discover a security vulnerability in this repository or the
`made-in.app` service, please report it privately:

- **Email:** security@made-in.app (replace with the maintainer's real address)
- **GitHub:** Open a private security advisory via the **Security** tab.

Please do not file public issues for security vulnerabilities.

## Scope

In scope: vulnerabilities in the validation logic, the deploy workflow,
the DNS-sync script, or abuse vectors that allow bypassing the
registration controls.

Out of scope: the contents of user-controlled subdomains, which are
the responsibility of the subdomain owner.
